# Apple Liquid Glass 天气应用 - 产品需求文档

## 1. 产品概述

一款具有苹果 iOS 设计风格的网页天气应用，集成了 Apple Liquid Glass 玻璃态效果组件，提供实时天气信息、多地点查询、小时级预报和空气质量展示等功能。面向追求高品质 UI 设计和流畅交互体验的用户群体。

## 2. 核心功能

### 2.1 功能模块

1. **主界面（天气首页）**：展示当前城市实时天气数据
2. **城市管理**：添加、切换和删除收藏城市
3. **小时级预报**：展示未来24小时天气趋势
4. **未来预报**：展示次日及后续天数天气预报
5. **空气质量**：展示 AQI 指数和相关指标

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 天气首页 | 动态背景 | 根据天气状况显示渐变动态背景（晴天蓝色渐变、雨天灰色渐变等） |
| 天气首页 | 主天气卡片 | Liquid Glass 玻璃态卡片，展示温度、天气图标、天气描述 |
| 天气首页 | 详情面板 | Liquid Glass 玻璃态卡片，展示体感温度、湿度、风速、气压等 |
| 天气首页 | 小时预报 | 横向滚动的24小时预报列表，每项显示小时、温度、天气图标 |
| 天气首页 | 未来预报 | 未来7天预报列表，每项显示日期、天气图标、高低温 |
| 城市管理 | 城市搜索 | 搜索框支持搜索城市名称 |
| 城市管理 | 城市列表 | 已收藏城市列表，支持滑动切换城市 |
| 空气质量 | AQI 面板 | Liquid Glass 玻璃态面板，展示空气质量指数和等级描述 |
| 空气质量 | 污染物详情 | PM2.5、PM10、O3、NO2、SO2、CO 等指标 |

## 4. 用户界面设计

### 4.1 设计风格

- **设计语言**：Apple iOS 18 设计风格，融合 Liquid Glass 玻璃态效果
- **主色调**：
  - 晴天：#007AFF（蓝色）、#5AC8FA（浅蓝）、#34C759（绿色）
  - 阴天：#8E8E93（灰色）、#636366（深灰）
  - 雨天：#5856D6（紫色）、#AF52DE（洋红）
- **玻璃态效果**：
  - 背景模糊：`backdrop-filter: blur(40px) saturate(180%)`
  - 边框：`1px solid rgba(255, 255, 255, 0.2)`
  - 阴影：`0 8px 32px rgba(0, 0, 0, 0.3)`
- **字体**：
  - 主标题：SF Pro Display / -apple-system / BlinkMacSystemFont
  - 温度数字：SF Pro Rounded / 200-300 字重
  - 正文：SF Pro Text
- **圆角**：
  - 主卡片：28px
  - 次级卡片：20px
  - 按钮：12px
- **图标**：SF Symbols 风格，使用 lucide-react 图标库

### 4.3 响应式设计

- **桌面端（> 1024px）**：双栏布局，左侧主天气，右侧详细数据和预报
- **平板端（768px - 1024px）**：单栏布局，卡片并排显示
- **移动端（< 768px）**：单栏垂直布局，全宽卡片

## 6. 视觉效果规格

### 6.1 Liquid Glass 效果参数

```typescript
interface LiquidGlassConfig {
  displacementScale: 50;      // 位移强度
  blurAmount: 0.08;           // 模糊程度
  saturation: 150;            // 饱和度
  aberrationIntensity: 1.5;   // 色差强度
  elasticity: 0.1;             // 弹性系数
  cornerRadius: 28;            // 圆角
  overLight: false;            // 深色遮罩
}
```

### 6.2 动画规格

- **页面过渡**：300ms ease-out
- **卡片悬停**：transform scale(1.02), 200ms ease
- **数据加载**：骨架屏 + 渐入动画
- **背景渐变**：15s linear infinite 循环动画

## 7. 数据来源

使用免费天气 API（如 Open-Meteo）获取天气数据，数据存储于浏览器 localStorage。
